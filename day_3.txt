1.主要学习了查询二进制

2.#include <limits.h>可以引入CHAR_CHAR,其可以自动检测bit，如我的windows系统固定为8位

3.#include <stdio.h>
#include <limits.h>
int main()
{
	unsigned char num = 65;
	int i;
	int bits = sizeof(num)*CHAR_BIT;
	for(i = bits - 1;i >= 0;i--){
		printf("%d",(num>>i)&1);
	}
	return 0;
 }
如上代码求出任何进制，num>>i 就是向右移动 i 位，后面的 &1 就是取出最后一位
不过 &2 是取出倒数第二位，&3 才是取出后两位
